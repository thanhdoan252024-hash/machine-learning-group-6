# Final Package Summary

## Recommended package for a new machine

Use the **Final Reproducible Package**. It contains:
- complete docs and final reports, including the final Word report under `report/`;
- P00–P13 AI Prompting Log;
- all 14 phase prompts;
- prompt-code mapping;
- reusable source code and evaluation utilities;
- tests and audits;
- raw and processed data;
- verified P09–P12 reference outputs, including direct full-data neighborhood-quality metrics for the final embedding;
- final embedding and figures;
- main source notebook and compact results notebook;
- pinned dependency file;
- command-line and notebook rerun tools;
- cross-platform launchers;
- checksum manifest.

## Submission package

The submission ZIP is a clean snapshot of the same verified case study, intended to hand in without temporary rerun folders.

## Prompt/docs package

The prompt/docs ZIP is a smaller companion containing the AI Prompting Log, per-phase prompts, prompt-code mapping, methodology docs, and notebooks for evidence/review.
