# Prompt Catalog

This folder contains one self-contained prompt per project phase, `P00` through `P13`.

Use `../05_AI_PROMPTING_LOG_MASTER.md` for the master chronological log and `../02_PROMPT_CODE_MAPPING.md` to map prompts to notebook/code phases.

The prompt set is part of the reproducibility record: prompts define the intended constraints and validation gates, while the source code and saved empirical outputs provide the executable evidence.
